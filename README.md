# Function-Counter

## Description

Function-Counter is an ASP.NET Core MVC application that scans source code files and automatically extracts, counts, and analyzes functions from source code files. I will be more useful when we want to do code migration, and we want to estimated time to complete that task

## Features

- Extract function names automatically
- Support multiple programming languages
- Download the extracted results

## Technologies Used

- ASP.NET Core MVC
- C#
- HTML
- CSS
- JavaScript
- Regular Expressions

## Usage

1. Enter the project path.
2. Click the **Scan** button.
3. View the extracted function names.
4. Click the **Download** button to export the results.
